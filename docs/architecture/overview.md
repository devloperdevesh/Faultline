# Faultline Architecture

Faultline aims to help developers identify security issues, review proposed
remediations, verify fixes, and preserve evidence.

Planned workflow:
1. Scan source code and dependencies.
2. Normalize and prioritize findings.
3. Propose reviewable remediation.
4. Run relevant verification checks.
5. Export findings and verification evidence.

This document describes the intended direction. It does not imply that every
component has been implemented.
